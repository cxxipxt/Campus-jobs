# Campus-jobs — Student Part-time Job Portal

เว็บไซต์จัดหางานพาร์ทไทม์สำหรับนักศึกษา มีระบบโปรไฟล์ ประกาศงาน ค้นหา บันทึกงาน สมัครงาน และติดตามผลการสมัคร

## คู่มือโครงการและฐานข้อมูล

อ่านภาพรวม ขอบเขต เทคโนโลยี โครงสร้างฐานข้อมูล และขั้นตอนเริ่มทำงานใน **[DATABASE_README.md](DATABASE_README.md)**

| เอกสาร | รายละเอียด |
|---|---|
| [คู่มือโครงการฉบับเต็ม](DATABASE_README.md) | ภาพรวม แบ่งงาน ติดตั้ง และทดสอบ |
| [คู่มือติดตั้งฐานข้อมูล](database/README.md) | วิธีนำเข้า SQL บนเครื่องแต่ละคน |
| [SQL โครงสร้างกลาง](database/schema.sql) | สร้างทั้ง 8 ตารางสำหรับ MySQL 8.0.16 ขึ้นไป |
| [Data Dictionary](database/data-dictionary.md) | คอลัมน์ คีย์ และเงื่อนไขข้อมูล |
| [แนวทางเชื่อมข้อมูลของทีม](database/team-guide.md) | ข้อตกลง Backend และการเตรียมข้อมูล |
| [ER Diagram](docs/erd/campus-jobs.drawio) | ดาวน์โหลดเพื่อเปิดใน draw.io |

## การแบ่งงานทีม

| ผู้รับผิดชอบ | ฟีเจอร์ | ตารางหลัก |
|---|---|---|
| **โอปอ** | บัญชีและโปรไฟล์นักศึกษา ทักษะ และลิงก์ Resume | `STUDENT`, `STUDENT_SKILL` |
| **มิก** | บัญชีนายจ้าง ข้อมูลบริษัท และประกาศงาน | `EMPLOYER`, `JOB_CATEGORY`, `JOB`, `JOB_SKILL` |
| **เตอร์** | ค้นหา บันทึก สมัครงาน ประวัติ และพิจารณาใบสมัคร | `APPLICATION`, `SAVED_JOB` |

## สถานะปัจจุบัน

มีเอกสารและ SQL โครงฐานข้อมูลกลางแล้ว ยังไม่มีเว็บไซต์ที่รันได้ และยังไม่ได้ทดสอบ SQL กับ MySQL จริงในเครื่องที่จัดทำไฟล์

ทุกคนใช้ schema เดียวกันบนฐานข้อมูลพัฒนาของตัวเอง และรัน `schema.sql` → `seed.sql` → `verify.sql` ตาม [คู่มือติดตั้ง](database/README.md)
