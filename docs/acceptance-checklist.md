# รายการทดสอบรับงาน
ยังไม่ได้ดำเนินการทดสอบ รายการนี้ใช้เมื่อมีโค้ดแล้ว

- [ ] นักศึกษาและนายจ้างสมัคร/ล็อกอิน/ออกจากระบบได้
- [ ] รหัสผ่านไม่ถูกต้องเข้าไม่ได้ และไม่เก็บรหัสผ่านต้นฉบับ
- [ ] อีเมลซ้ำภายในประเภทบัญชีเดียวกันถูกปฏิเสธ
- [ ] นักศึกษาแก้โปรไฟล์ เพิ่ม/ลบทักษะ และลิงก์ Resume ได้
- [ ] ทักษะชื่อเดิมของเจ้าของคนเดิมไม่ซ้ำ
- [ ] นายจ้างสร้าง แก้ไข เปิด/ปิดงาน และระบุหลายทักษะได้
- [ ] ค้นหาชื่อ กรองประเภท สถานที่ และค่าจ้างได้
- [ ] บันทึกงานซ้ำไม่เกิดหลายรายการ และยกเลิกได้
- [ ] งานเปิดสมัครได้ สถานะเริ่มต้น Pending
- [ ] สมัครซ้ำถูกปฏิเสธ รวมกรณีคำขอซ้ำพร้อมกัน
- [ ] งานปิดสมัครไม่ได้ และใบสมัครเดิมยังอยู่
- [ ] นายจ้างดูผู้สมัครและเปลี่ยนสถานะงานของตนเองได้
- [ ] นายจ้าง A ดู/แก้ประกาศหรือใบสมัครของนายจ้าง B ไม่ได้ แม้เปลี่ยน ID ในคำขอ
- [ ] นักศึกษา A ดู/แก้ข้อมูลส่วนตัว ใบสมัคร และรายการบันทึกของ B ไม่ได้
- [ ] นักศึกษาเห็นผลที่นายจ้างเปลี่ยน
- [ ] ค่าจ้างติดลบหรือข้อมูลผิดรูปแบบถูกปฏิเสธฝั่งเซิร์ฟเวอร์
