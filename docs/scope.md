# ขอบเขตระบบ

## นักศึกษา
- สมัครสมาชิก เข้าสู่ระบบ ออกจากระบบ
- จัดการชื่อ อีเมล เบอร์โทร สาขา ทักษะ และลิงก์ Resume
- ค้นหาชื่องาน กรองประเภทงาน สถานที่ และค่าจ้างต่อชั่วโมง
- ดูรายละเอียดงาน นายจ้าง และทักษะที่ต้องการ
- บันทึก/ยกเลิกบันทึกงาน
- สมัครงานที่เปิดรับ โดยสมัครประกาศเดิมซ้ำไม่ได้
- ดูประวัติและสถานะใบสมัครของตนเอง

## นายจ้าง
- สมัครสมาชิก เข้าสู่ระบบ ออกจากระบบ
- จัดการชื่อบริษัทหรือร้านค้า อีเมล เบอร์โทร และที่อยู่
- เพิ่ม/แก้ไขประกาศ ประเภทงาน สถานที่ ค่าจ้าง เวลางาน และทักษะที่ต้องการ
- เปิด/ปิดประกาศของตนเอง
- ดูผู้สมัคร โปรไฟล์ ทักษะ และลิงก์ Resume ของผู้สมัครในงานของตนเอง
- เปลี่ยนสถานะใบสมัครในงานของตนเอง

## กฎที่ใช้ร่วมกัน
- JOB.status: Open / Closed; ค่าเริ่มต้น Open
- APPLICATION.status: Pending / Reviewing / Accepted / Rejected; ค่าเริ่มต้น Pending
- งานปิดแล้วรับใบสมัครใหม่ไม่ได้ และต้องเก็บประวัติเดิม
- APPLICATION ห้ามคู่ student_id + job_id ซ้ำ
- SAVED_JOB ห้ามคู่ student_id + job_id ซ้ำ
- ทักษะเก็บหนึ่งทักษะต่อแถว ตัดช่องว่างส่วนเกินก่อนบันทึก
- ทุกคำขอแก้ข้อมูลหรือดูข้อมูลส่วนตัวต้องตรวจผู้ใช้และเจ้าของข้อมูลฝั่งเซิร์ฟเวอร์
- นายจ้างเห็นโปรไฟล์และลิงก์ Resume ปัจจุบัน ไม่ใช่สำเนาวันสมัคร
- ประเภทงานกำหนดล่วงหน้า หนึ่งประกาศเลือกหนึ่งประเภท
- location เป็นข้อความ ค้นหาตามคำ หากต้องการตัวเลือกจังหวัดต้องตกลงโครงสร้างเพิ่ม
- นักศึกษาใช้ Microsoft @kmutt.ac.th หรือ Google @mail.kmutt.ac.th เท่านั้น Backend ตรวจผู้ให้บริการก่อนใช้ university_username เชื่อมบัญชี ไม่มีรหัสผ่านนักศึกษาในระบบ
- รหัสผ่านนายจ้างจัดเก็บเป็น hash ด้วยไลบรารีสำหรับรหัสผ่าน ไม่เก็บข้อความต้นฉบับ

## ไม่รวม
แชต ชำระค่าจ้าง รีวิว อัปโหลด Resume จับคู่งานอัตโนมัติ แจ้งเตือนอีเมล/SMS และหน้าผู้ดูแล

## เรื่องที่ทีมต้องตกลงก่อนเขียน
- ภาษา backend และเวอร์ชัน รวมถึงรูปแบบ session และการแยกบทบาทตอนล็อกอิน (ฐานข้อมูลใช้ MySQL 8.0.16 ขึ้นไป)
- ยืนยันฟิลด์โปรไฟล์หากต้องการบังคับเพิ่มจาก v2 ซึ่งอนุญาต phone/major/resume_url ของนักศึกษา และ phone/address ของนายจ้างเป็น NULL
- อนุญาตให้เปิดงานอีกครั้งหรือย้อนสถานะใบสมัครหรือไม่
- รูปแบบชื่อทักษะร่วมกัน (v1 เปรียบเทียบข้อความทั่วไปโดยไม่แยกตัวพิมพ์เล็ก/ใหญ่)
